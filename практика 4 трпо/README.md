# Практическая работа №4. PHP: основы языка, запросы и обработка HTML-форм

Учебное веб-приложение на PHP для учёта сотрудников, фильтрации списка записей и обработки HTML-формы добавления новой заявки с серверной валидацией.

## Используемые технологии
PHP 8+ (встроенный веб-сервер, обработка `GET` и `POST`, работа с CSV-файлами, фильтрация и валидация данных)
HTML5 / CSS3 (семантическая разметка, формы, табличное представление данных)

## Требования и запуск проекта

1.Клонируйте репозиторий и перейдите в корневую директорию проекта
git clone https://github.com/jamushka/tr_po_php

2.Запустите встроенный PHP-сервер из корня проекта
php -S localhost:8000 -t public

3.Откройте приложение в браузере по адресу
http://localhost:8000
